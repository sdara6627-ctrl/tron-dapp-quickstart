# 钱包连接问题排查指南

## TokenPocket 扩展无法连接的问题

如果你已经安装了 TokenPocket 浏览器扩展，但选择 TokenPocket 钱包时跳转到官网，请按以下步骤排查：

### 1. 确认扩展已安装并启用

- 打开 Chrome 浏览器，访问 `chrome://extensions/`
- 确认 **TokenPocket** 扩展已安装且**已启用**（开关是打开状态）
- 如果扩展被禁用，请启用它

### 2. 检查扩展是否正确注入

打开浏览器控制台（F12），在 Console 中输入：

```javascript
console.log(window.tokenpocket)
```

如果显示 `undefined`，说明扩展没有注入。可能的原因：
- 扩展需要刷新页面才能注入
- 扩展被浏览器安全策略阻止
- 扩展版本过旧，不支持当前页面

### 3. 刷新页面

扩展注入需要时间，请：
1. **完全刷新页面**（Ctrl+Shift+R 或 Cmd+Shift+R）
2. 等待 2-3 秒让扩展完成注入
3. 然后再尝试连接钱包

### 4. 检查扩展权限

- 在 `chrome://extensions/` 中，找到 TokenPocket 扩展
- 点击「详细信息」
- 确认「在所有网站上」或「在特定网站上」的权限已授予

### 5. 检查扩展版本

- 确保 TokenPocket 扩展是最新版本
- 旧版本可能不支持某些 API

### 6. 使用调试工具

项目已添加钱包扩展检测工具。在开发环境下，打开控制台会看到：

```
🔍 钱包扩展检测结果: { TokenPocket: true/false, ... }
```

如果 TokenPocket 显示 `false`，说明扩展未正确注入。

### 7. 临时解决方案

如果以上方法都不行，可以尝试：

1. **使用 TronLink 扩展**：TokenPocket 和 TronLink 都支持 TRON，如果 TokenPocket 有问题，可以先用 TronLink
2. **使用移动端钱包**：TokenPocket 移动端钱包通常更稳定
3. **检查网络**：确保能访问 TRON 网络

### 8. 常见问题

**Q: 为什么选择 TokenPocket 会跳转到官网？**  
A: 适配器检测不到扩展时会跳转到官网引导安装。如果已安装但仍跳转，说明检测失败，请按上述步骤排查。

**Q: 检测超时时间是多少？**  
A: 已设置为 5 秒。如果扩展加载较慢，可能需要刷新页面。

**Q: 可以禁用自动跳转吗？**  
A: 可以，在 `src/App.tsx` 中设置 `openUrlWhenWalletNotFound: false`，但这样用户如果没安装扩展就不知道如何安装了。

## 其他钱包的类似问题

其他钱包（OKX、BitKeep 等）如果也有类似问题，排查步骤相同：
1. 确认扩展已安装并启用
2. 刷新页面
3. 检查控制台是否有错误
4. 使用调试工具检查扩展是否注入
